# 🍰 Doceria Vasconcelos

Site institucional desenvolvido para a **Doceria Vasconcelos**, com o objetivo de apresentar e divulgar seus produtos de forma moderna, atrativa e responsiva.

## 📌 Sobre o projeto

O projeto consiste em uma **One Page** para divulgação da doceria, apresentando seus principais produtos e informações de forma organizada e visualmente agradável.

O desenvolvimento teve como foco a criação de uma interface responsiva, utilizando recursos de HTML, CSS, JavaScript e Tailwind CSS.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Tailwind CSS

## 🎨 Funcionalidades

- Layout One Page
- Design responsivo para diferentes dispositivos
- Apresentação dos produtos
- Seções informativas
- Interações utilizando JavaScript
- Estilização utilizando Tailwind CSS
- Interface moderna e intuitiva

## 💻 Objetivo

Este projeto foi desenvolvido como prática de **desenvolvimento Front-End**, buscando aplicar conceitos de estruturação de páginas, estilização, responsividade e interatividade.
